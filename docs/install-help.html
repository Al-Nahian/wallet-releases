Installing Wallet

Because Wallet isn't distributed through the Google Play Store, Android's built-in Play Protect scanner shows a warning before you install it — this happens for every app installed this way, regardless of how safe it actually is, simply because Play Protect has no install history for a developer's own signing certificate outside the Play Store. It isn't a sign that anything is wrong with the app.

Why you're seeing this

Play Protect's warning (something like "Unsafe app blocked" or "App not verified by Play Protect") is based on how an app was distributed and how many other people have installed that exact build before you — not on any actual scan result. A brand new release, or one signed with a certificate Play Protect hasn't seen much of yet, triggers the same generic caution every time.

How to continue the install

  1. When the warning appears, tap "More details" (or similar, wording varies by Android version).
  2. Tap "Install anyway".
  3. If Android later blocks the SMS/notification-access toggles inside Wallet (under Settings → Automation), that's a separate, unrelated Android security feature — Wallet has its own step-by-step guide for that built right into the app, shown the first time you turn either toggle on.

What Wallet actually does with your data

Everything you enter stays on your device by default — see the full Privacy Policy for exactly what's collected and when (short version: nothing, unless you choose to sign in for optional cloud backup).
